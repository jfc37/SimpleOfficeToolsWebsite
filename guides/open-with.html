Guides/Open files from File Explorer

Open files from File Explorer

Send a PDF or supported image from File Explorer straight into your workspace.

Before you start: Install a version of Simple Office Tools that includes Windows file associations.

  1. Find the file

    Open File Explorer and find the PDF or supported image you want to work on.

  2. Choose Open with

    Right-click the file, open Open with, and choose Simple Office Tools.

  3. Check the import

    The app opens or brings the current workspace forward. Check that the file appears in Arrange.

  4. Continue your document

    Add any other files, check the page order, then continue to edit and review. Export your finished document as a new PDF.

Tip: Use Open with for a one-off choice. Follow the default PDF app guide if you want PDFs to open here when double-clicked.

Common questions

What if Simple Office Tools is missing from Open with?

Choose another app to look for it in the Windows picker. If it is still missing, install or update the app; you can use Browse files inside the app in the meantime.

Does this change my default PDF app?

Choosing Simple Office Tools from Open with opens that file. Setting it as the default is a separate Windows choice.
