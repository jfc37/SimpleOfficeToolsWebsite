Make Simple Office Tools your default PDF app

Choose Simple Office Tools as the Windows app that opens when you double-click a PDF.

Before you start: Install a version of Simple Office Tools with Windows file associations. This changes the default for PDF files on your Windows account.

  1. Open the Windows app picker

    In File Explorer, right-click a PDF. Choose Open with, then Choose another app.

  2. Select Simple Office Tools

    Choose Simple Office Tools in the list of available apps.

  3. Make it the default

    Choose Always to use it for PDF files. Choose Just once if you only want to open this file.

  4. Test another PDF

    Double-click another PDF in File Explorer. Check that Simple Office Tools opens it and that the expected document appears in Arrange.

Tip: You can change your choice later through Windows Settings → Apps → Default apps, or choose a different app with Open with.

Common questions

Does this change how images open?

This guide changes the association for .pdf files. Other file types keep their own default apps.

Can I open a PDF elsewhere without changing the default?

Yes. Right-click the file and use Open with to select a different app for that occasion.
