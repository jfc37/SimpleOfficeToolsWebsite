Guides/Save and use image presets

Save and use image presets

Save an image together with its size and position, then place it again with one click.

Image presets are saved on this device.

Create an image preset

  1. Place and position the image

    Add an image to the PDF and set its size and position exactly as you want it.

    The saved preset will remember both.

  2. Open Save as preset

    With the image selected, open Image details and expand Save as preset.

  3. Name the preset

    Enter a unique name that will make the preset easy to recognise later.

    For example:

    Client logo – top right

    Choose Save.

    If the name is blank or already being used by another preset, Simple Office Tools asks you to correct it.

    Saving a preset does not make any additional changes to the PDF.

  4. Use an image preset

  5. Open Image presets

    Choose Back to images, then open Image presets.

    Your saved presets appear here.

  6. Choose a preset

    Select the preset you want to use.

    The image is immediately inserted on the current page using its saved size and position.

    If the saved image cannot fit on the current page at that exact size and position, the page is left unchanged and Simple Office Tools explains the problem.

  7. Continue editing if needed

    Once inserted, the preset becomes a normal selected image.

    You can move it, resize it, copy it to other pages or continue editing the PDF.

Tip: Presets are useful for things such as logos, approval stamps and signatures that need to appear in a consistent place.

For example, you could save a company logo positioned in the top-right corner and reuse it across future documents.

Common questions

Are image presets shared with other computers?

No. Image presets are currently saved on the device where they were created.

What happens if I rename or delete a preset?

It changes the saved preset only. Images you have already placed in PDFs are not changed.

Does a preset remember the page number?

No. It remembers the image, size and position. You choose the page where you want to insert it.
