Add an image to a PDF

Add a signature, stamp, logo or other image to a PDF page and position it where you need it.

Before you start: Have the image you want to use saved on your computer. A transparent-background PNG often works well for signatures and stamps.

  1. Open the image tools

    In Customise, choose Add.

    Select Add new image and choose an image from your computer.

    The image is added to Saved images so you can use it again.

  2. Place the image

    Choose the image from Saved images, then click the PDF page where you want it to appear.

    The image is added to the page and selected automatically.

  3. Move and resize it

    Drag the image to move it.

    Use its resize handles to change its size.

    The aspect ratio stays locked so the image does not become stretched or distorted.

  4. Set an exact position or size

    With the image selected, use Image details for more precise control.

    Under Position, set its horizontal and vertical distance from the page edges.

    Under Size, enter the required width or height.

    Changes made on the page and in Image details stay in sync.

  5. Export and check the PDF

    Continue to Review & Export and export the PDF.

    Reopen the exported file and check the image position and clarity before sharing it.

Tip: If you need the same image in exactly the same place on several pages, use Copy to pages instead of placing each copy manually.

If you regularly use the same image, size and position, save it as an Image preset.

Common questions

Is a signature image a digital signature?

No. It is a visible image placed on the PDF. It does not create a certificate-based digital signature.

Can I reuse an image after adding it once?

Yes. Images added through Add new image are available under Saved images on that device.
