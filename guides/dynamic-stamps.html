Create and place reusable stamps

Create reusable stamps with automatic details, dates and prompted values, then place a frozen copy on your PDF.

Before you start: Open a PDF with Edit PDF, continue to Customise and choose Stamps.

  1. Create your template

    A new library starts with No stamps yet. Choose Create stamp and enter a name. Drag an outer edge or corner handle, or enter Width and Height in PDF points (pt), to resize the artboard. Enlarging adds empty canvas; shrinking stops at existing content without scaling it. Left/top edge changes rebase element positions while retaining their visual size and location. The Boundary button selects the artboard; Width and Height provide keyboard resizing. The designer covers workflow progress while keeping the app header visible. On compact windows, switch between Canvas and Properties to keep editing.

  2. Add and edit elements

    Add Text, Dynamic text, Prompt text, Shape or Image. Select an element on the canvas, edit its properties, and drag to move or resize it. X and Y specify position from the artboard top-left in points. After selecting on the canvas, Arrow keys move 1 pt and Shift + Arrow moves 10 pt, clamped inside the artboard; native text/picker controls keep their normal arrow-key behavior. Width and Height edit the selected element's box in PDF points without changing its font size. Images keep their aspect ratio when dragged or resized numerically: changing Width also updates Height, and changing Height updates Width. Only Image has Send to front and Send to back for overlays and logos. New elements reuse the last-used appearance and size of their own type in this designer session; content, sources, prefixes and prompt labels reset. New Image always asks for a fresh asset and respects its own ratio. PNG and JPEG images keep their original format, including PNG transparency. If an image cannot be used, an inline message appears and your existing image and stamp stay unchanged.

    Select Stamp boundary to set Background colour, choose/replace/remove a separate Background image, and enter Corner radius in pt. The base image fits uniformly and centrally without stretching; uncovered areas show the colour. The rounded boundary clips the background and all elements, leaving transparent outer corners. Backgrounds are embedded in the template and frozen with each placement.

    Dynamic text supports Name, Initials, Email, Date, Time and Date & time. Only date/time sources have a Format choice. Dynamic text can include Prefix text, for example Checked by: followed by your Name. Prompt text defines a label, prefix, placeholder, default, required status and helper text for a single-line input. Label names the field in Complete stamp; Prefix text appears before its entered value in the stamp, for example Employee: John Smith. Prefix and value share the element's text style and wrapping.

  3. Save and reuse

    Choose Save stamp. The designer stays open while saving; editing, Save and Cancel are unavailable until the attempt finishes. If saving fails, your changes remain in the designer with an inline message so you can retry. When saving succeeds, the designer closes and the stamp appears in the library. Cancel discards an idle, uncommitted draft. Open the card actions (three dots), then choose Edit to reopen the editable template, or Delete to remove it from the library. Your details stores Name, Initials and Email locally, separately from templates. Designer previews use your saved details, with neutral examples while those details are missing.

  4. Choose a stamp and click the page

    Select its library card. If required identity is missing, Your details requests only the fields that template needs. Save and continue stores those values and starts placement. Cancel aborts placement. Move the pointer over the page to see the saved stamp size and click where it belongs. Escape or Cancel placement aborts without adding a stamp.

  5. Complete any prompted values

    A template without prompts is placed immediately. Otherwise Complete stamp shows all prompt fields and a live preview. Fill every required field, then choose Place stamp. The confirmed pixels are frozen at the page location already clicked. Date/time uses your local timezone when you choose Place stamp; the final confirmation appearance is frozen. Cancel creates no partial annotation.

  6. Edit, Review and export

    The placed stamp is one object. Select it to move, resize or Delete it. Its size and position also appear in the existing Image details controls. Copy to pages reuses its frozen appearance on other pages. Placed dynamic stamps do not show Save as preset; manage reusable definitions in Stamps. Ordinary images added through Add still support image presets. Undo and Redo work for placement and edits. Rearranging pages keeps the stamp on its original logical page. Continue to Review and export the PDF.

Frozen copies: Editing Your details or editing/deleting the template never changes stamps already placed. Each new placement resolves its own values. Templates and identity stay on this device; this first version has no library import/export button.

Common questions

Can I edit a placed stamp's text?

A placed copy is a frozen image annotation. Delete it, edit the reusable template or prompt values, and place a new copy to change its content.

Why is a font different on another device?

Templates use installed fonts with a platform fallback when a font is unavailable. A placed stamp carries its rendered appearance, so the exported copy does not require that font. Large enlargements can reveal pixels.
