Export PDF tables to Excel

Extract suitable detected table data into an XLSX workbook for checking and further work in Excel.

Before you start: Use a PDF with clear rows and columns. This is table extraction, not a conversion of every PDF layout.

  1. Open the PDF

    Add the source PDF and include the pages containing the tables you need.

  2. Continue to Review & Export

    Finish any page changes, then continue until the export choices appear.

  3. Choose Excel (.xlsx)

    Under Choose a format, select Excel (.xlsx), then choose the export action and save the workbook.

  4. Check the workbook

    Open the XLSX file in Excel. Compare headings, row boundaries, dates, decimal values and totals with the original PDF before using the data.

Tip: OCR a scanned table first. Recognition and table detection can both make mistakes, so keep the PDF open while reviewing the workbook.

Common questions

What if no table is found?

The page may not have a suitable table structure. Try a clearer source, or run OCR first when the table is scanned.

Will formatting outside the table be included?

No. Excel export focuses on suitable detected tables rather than reproducing the full PDF page.
