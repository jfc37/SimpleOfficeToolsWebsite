Copy an image to other pages

Place an image once, then copy it to multiple pages using exactly the same size and position.

Before you start: Add and position the image on one page first.

  1. Select the image

    Click the image on the page.

    This opens Image details.

  2. Open Copy to pages

    Expand Copy to pages.

    Enter the page numbers where you want the image copied.

    You can enter individual pages and ranges, for example:

    1-4, 7, 9

    Page numbers refer to the final document order.

  3. Copy the image

    Apply the copy.

    The image is added to each target page using exactly the same size and position as the original.

    The page containing the original selected image is excluded automatically.

  4. Check the result

    When the copy succeeds, Simple Office Tools tells you how many pages were updated.

    Review the target pages before exporting.

    If the image cannot fit at its saved size and position on one or more target pages, the copy is not made and Image details explains the problem.

Tip: Copying the image to several pages is treated as one action, so a single Undo reverses the whole copy operation.

Common questions

Can the copies have different positions on different pages?

The initial copies use exactly the same size and position as the selected image. You can edit an individual copy afterwards if required.

What happens if one of the target pages is too small?

The copy is not applied. Adjust the image size or position first, then try again.
