Guides/Fillable forms

Create a fillable PDF form

Add fields to a PDF so someone can type or tick answers in a standard PDF reader.

Before you start: Open the blank PDF you want people to complete.

  1. Open Forms

    Choose Browse files to import the PDF, continue to Arrange, then choose Continue to edit and Forms beside the page.

  2. Add and detect fields

    Choose Text box or Checkbox and place the field over its answer area. Choose Detect form fields to find more candidates, select the pages to scan, and review the suggestions before applying them. Remove any field that does not belong.

  3. Size and check the fields

    Move and resize each field so it lines up with the printed prompt. Check that the field type matches the answer you expect.

  4. Export and test

    Choose Continue to review, then choose Export, PDF, Export PDF and save the file. Open it in a PDF reader, type into the text boxes and tick the checkboxes.

Tip: Standard PDF export keeps text boxes and checkboxes fillable. The signature tool creates a text box placeholder, not a certificate based digital signature.

Common questions

Which fields does this guide cover?

This guide covers text boxes, checkboxes, initials and a signature placeholder.

Will the fields work after export?

Text boxes and checkboxes remain fillable in a standard PDF. Test the saved PDF in the reader your recipients use.
