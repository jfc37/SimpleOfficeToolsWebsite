Move PDF content between pages

Move a section within a page or onto another page to improve a PDF’s layout.

Before you start: Add the PDF and open Arrange. Keep the original so you can compare the result.

  1. Open Rearrange content

    In Arrange, choose Documents. Use the move-content icon on the document row, labelled Move sections between pages, to open Rearrange content.

  2. Select the source content

    In Select content, choose the source page and drag a rectangle around the section to move.

  3. Position it on the destination

    Under Position destination, choose a page. Drag the selected box into place and check for overlaps. Choose Apply move.

  4. Repeat and finish

    Move any remaining sections, then choose Apply and close. Use Undo last move if a move needs correcting. Back in Arrange, exclude any page that is now empty.

  5. Export and compare

    Continue through review and export a new PDF. Check the source and destination pages for missing content, overlaps and unwanted blank pages.

Tip: Rearrange content before adding text edits, annotations or form fields. If you return after Customise, read the warning about losing earlier changes. If a selection cannot be moved safely, leave it unchanged and adjust the selection or use the source document.

Common questions

Can I move content to another page?

Yes. The destination page selector lets you position the selected section on another page in the document.

Is this the same as reordering pages?

Rearrange content moves a selected section. To change the order of whole pages, use All pages in Arrange.
