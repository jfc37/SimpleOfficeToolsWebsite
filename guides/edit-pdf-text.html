Correct text in a PDF

Fix a typo in a text based PDF without going back to the original document.

Before you start: Open the PDF in Simple Office Tools. This workflow edits selectable text; OCR can select, copy and highlight a scan, but does not make its visible lettering editable.

  1. Open Edit text

    Choose Browse files to import the PDF, continue to Arrange, then choose Continue to edit and Edit text beside the page.

  2. Select the text box

    Under Text boxes, choose Single lines, Inline text boxes or Whole page. Select a box outlined in blue that contains the wording you want to correct.

  3. Make the correction

    Edit the selected wording. If the line wraps, adjust the text box and check its position. Click outside the box to review it. Use Apply changes when you are ready, or Undo last change while reviewing.

  4. Check and export

    Review the visible wording and spacing, choose Continue to review, then choose Export, PDF, Export PDF and save the file.

Tip: Use Discard all changes if the proposed edits do not look right, then start again from the original PDF.

Common questions

Can I edit a scanned page?

OCR helps you select, copy and highlight words in a scan. It does not turn the visible scanned lettering into editable text.

Will formatting stay the same?

Check the edited line and its spacing before exporting. Different PDFs can use different text boxes and fonts.
