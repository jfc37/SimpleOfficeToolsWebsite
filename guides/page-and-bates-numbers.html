Guides/Add page or Bates numbers

Add page numbers or Bates numbers to a PDF

Number pages automatically, or build sequential Bates labels with a prefix, starting number, padding and suffix.

Before you start: Put the included pages in their final order before applying a sequence.

  1. Open Finish

    In Customise, choose Finish, then choose Page numbers or Bates numbering.

  2. Set the sequence

    For page numbers, choose a format and page range. For Bates labels, set the prefix, start number, padding and optional suffix.

  3. Choose placement and appearance

    Pick a position, adjust offsets if needed, then set the font size and colour. Move through the preview pages to check the result.

  4. Save, export and verify

    Choose Save & close, export the PDF, and reopen it. Check the first and last numbered pages and any page where size or orientation changes.

Tip: Bates padding keeps labels the same width—for example, a start value of 1 with six digits becomes 000001.

Common questions

Can I number only part of the PDF?

Yes. Set the start and end page for the numbering range. Leave a boundary blank to use the first or last page.

What if I reorder pages afterward?

Review the numbering again before export. Applying the sequence after finalising page order is the safest workflow.
