Getting started

What is Simple Office Tools?

It is a Windows app for everyday PDF work such as combining, arranging, editing, adding form fields and exporting.

How do I start the trial?

Download the stable installer, open the app, choose Start a free trial and enter your email address. There is no credit card required; naming the device is optional, then choose Continue to app when setup is complete.

What does the app need?

The app supports Windows 10 build 19041 or later or Windows 11 on an x64 computer. Printing into the app additionally requires Windows 11 version 24H2 or later and an installed Simple Office Tools printer.

What happens when the 30-day trial ends?

The trial does not automatically become a paid subscription. Choose a licence if you want to continue using the app after the trial period.

Does the app need the internet?

PDF editing, organising and export happen on your computer. Internet is needed for installation, activation, licence verification and updates.

Licences and payment

What does a licence cost?

The current price is NZ$150 per Windows device per year, excluding GST. See the full plan details on the pricing page.

Is a licence per device?

One paid seat covers one device at a time, so you need one licence for each computer used.

How does renewal work?

A paid licence renews annually unless cancelled before renewal. Cancelling stops future renewals and access continues to the end of the paid term; see the payment terms.

How do I activate a licence I already bought?

In the app choose Claim a licence, paste the transaction ID from your invoice and choose Claim licence.

Where are the refund terms?

Read the refund policy for the current eligibility and request process.

Working with PDFs

How do I combine PDF files?

Use Browse files to import them, then use Arrange to order and include the pages before exporting a new PDF. Read the client-pack guide.

Can I correct text in a PDF?

Yes, for PDFs with an existing editable text layer. Choose Edit text, select a blue outlined text box, choose a grouping and apply the changes. Scans need the separate OCR workflow. Read the edit text guide.

Does OCR make a scan editable?

OCR permits selecting, copying and highlighting words in a scan. It does not make the visible scanned lettering editable. Read the OCR guide.

Can I export a PDF to Word?

Yes. Word export is a beta feature that reconstructs supported text, images and tables in a DOCX document. Complex layouts can change and some content may remain as images, so compare the result with the original PDF. Read the Word export guide.

Can I export PDF tables to Excel?

Yes, when the PDF contains suitable detected tables. Excel export extracts table data rather than reproducing the entire page, so check the workbook against the original PDF. Read the Excel export guide.

Can I add fillable fields?

Open Forms beside the page, then choose the Detect form fields button when appropriate. Under Add fields manually, drag a text box or checkbox onto the document; text boxes and checkboxes remain fillable in standard PDF export.

Is the signature tool a digital signature?

The standard signature tool creates a text box placeholder. It is not a certificate based digital-signature field.

How do I print into the app?

On Windows 11 version 24H2 or later, choose the installed Simple Office Tools printer from another app. Read the print guide.
